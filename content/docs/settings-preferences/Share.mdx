## How to Share Usage Data

To share usage data with Folio:
1. Click on the `⚙️` Settings icon in the bottom navigation bar of the Folio app.
2. Toggle the `Share Usage Data` switch button.
3. Click `Save` to save your changes.
4. Your anonymous data sharing is now enabled.

## ⁉️ FAQs

<Accordions>
  <Accordion title="💽 What Does Enabling Usage Data Sharing Mean?">
   - This data **doesn't include your personal or private information**—only anonymous usage data that helps us enhance Folio. For more details, check our privacy policy [here](https://savewithfolio.com/legal/privacy/): https://savewithfolio.com/legal/privacy/
  </Accordion>
  <Accordion title="🔁 Can I disable this feature?">
   - Yes, you can disable the usage data sharing feature at any time
  </Accordion>
  <Accordion title="📊 What type of data is shared?">
    The shared data includes:
    - Crash issues on Android and iOS.
    - Anonymous information about how you use the app (like features you interact with, general performance, and app crashes) to help improve the experience.
  </Accordion>
  <Accordion title="⛔ Is the data shared with third parties?">
   - No. The data is only used internally by the Folio team for app improvement.
  </Accordion>
  <Accordion title="✅ Why should I enable it?">
    Sharing anonymous data helps the Folio team:
      - Identify bugs and performance issues.
      - Improve existing features.
      - Decide which new features to build.
  </Accordion>
</Accordions>
