## Sync From Pocket (`Sign In`)

Sync all your saves from Pocket to Folio with just a single click by signing in to Pocket and allowing content to sync to Folio. 

To do this: Click `⚙️` in the Bottom Nav Bar → `Import` → `Pocket (Sign In)` → `Allow Sync`.

![Pocket Sync](/getting-started/import-sync/Pocket_Sync.png)

## Import Pocket (`.ZIP` or `.CSV`)

<Callout type="info" title="Note">
This is another way to import content from Pocket using a `.ZIP` or `.CSV` file
</Callout>
1. **Export** Content From Pocket (.ZIP or .CSV): Go to [Export](https://getpocket.com/export) → Click **`Export CSV file`** button → Check your email for the attached `(.CSV)` file.
2. **Upload** Pocket (`.CSV`) File to Folio: Click `⚙️` in the Bottom Nav Bar → `Import` → `Pocket (.ZIP or .CSV)` → Upload Pocket File `(.ZIP or .CSV)`.

![Pocket Import](/getting-started/import-sync/Pocket_Import.png)

## Import Instapaper (`.CSV`)

If you're using Instapaper, you can export all your content from the [account settings](https://www.instapaper.com/user), then upload the Instapaper `.CSV` file to Folio.
1. **Export** Content From Instapaper (`.CSV`): Go to [`Setting`](https://www.instapaper.com/user) Page → Click `Send .CSV file to your email` → Check your email for the attached `(.CSV)` file.
2. **Upload** Instapaper (`.CSV`) File to Folio: Click `⚙️` in the Bottom Nav Bar → `Import` → `Instapaper(.CSV)` → `Upload Instapaper File (.CSV)`.

![Instapaper Import](/getting-started/import-sync/Instapaper_Import.png)

## Import Matter (`.ZIP` or `.CSV`)

Using Matter? You can export all your content from the account settings, then upload the Matter `.ZIP` or `.CSV` file to Folio.
1. **Export** Content From Matter (.ZIP or .CSV): Go to [`⚙️ Settings`](https://web.getmatter.com/settings) → Click `Export` Button → Check your email for the attached `(.CSV)` file.
2. **Upload** Matter File to Folio: Click `⚙️` in the Bottom Nav Bar → `Import` → `Matter(.ZIP or .CSV)` → `Upload Matter File (.ZIP or .CSV)`. 

![Matter Import](/getting-started/import-sync/Matter_Import.png)

## Import Raindrop.io (`.CSV`)

To import your saves from Raindrop.io, you can export your collections as a `.CSV` file and then upload it to Folio.
1. **Export** Content From Raindrop.io (`.CSV`): Go to [`Settings`](https://app.raindrop.io/settings/export) → Click `Export as CSV` → Check your email for the attached `(.CSV)` file.
2. **Upload** Raindrop.io (`.CSV`) File to Folio: Click `⚙️` in the Bottom Nav Bar → `Import` → `Raindrop.io(.CSV)` → `Upload Raindrop.io File (.CSV)`.

![Raindrop.io Import](/getting-started/import-sync/Raindrop_Import.png)

## Import Readwise Reader (`.CSV`)

To import your saves from Readwise Reader, you can export your highlights as a `.CSV` file and then upload it to Folio.
1. **Export** Content From Readwise Reader (`.CSV`): Go to [`Settings`](https://readwise.io/export) → Click `Export All Highlights` → Check your email for the attached `(.CSV)` file.
2. **Upload** Readwise Reader (`.CSV`) File to Folio: Click `⚙️` in the Bottom Nav Bar → `Import` → `Readwise Reader(.CSV)` → `Upload Readwise Reader File (.CSV)`.

![Readwise Reader Import](/getting-started/import-sync/Readwise-reader_Import.png)
